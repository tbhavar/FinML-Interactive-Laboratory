FinML Interactive Laboratory 💡
Project Description
Welcome to the FinML Interactive Laboratory, an open-source, educational web application designed to demystify core Machine Learning (ML) concepts through direct application in the financial domain.

Developed as a single, lightweight HTML file, this project is ideal for students, financial analysts, and consultants looking to understand the intuition behind quantitative finance models without needing to run complex code. By providing an interactive sandbox, the lab allows users to visually manipulate model parameters and immediately observe the impact on outcomes like risk prediction and price forecasting.

🚀 Technical Highlights
This project adheres to the principle of minimalism and portability.

Deployment: Designed as a single index.html file, making it instantly deployable via GitHub Pages.

Styling: Tailwind CSS is used for a professional, responsive, and dark-centric color theme, ensuring a stunning visual experience on both desktop and mobile devices.

Interactivity: Pure Vanilla JavaScript drives all the simulations, calculations, and real-time visualization updates.

Theme: Includes a functional button to switch seamlessly between Dark Theme (default, professional aesthetic) and Light Theme.

🎓 Interactive Modules and Learning Outcomes
The repository hosts three core modules, each demonstrating a fundamental financial ML technique:

Module 1: Stock Price Regression (Forecasting)
Concept: Demonstrates Polynomial Regression and the critical Bias-Variance Trade-off.

Interaction: Users manipulate a Model Complexity Slider and observe how the predicted price line fits the historical data.

Key Lesson: Visually identifies Underfitting (low complexity, high bias) and Overfitting (high complexity, high variance) and links these concepts directly to the Mean Squared Error (MSE) metric.

Module 2: Credit Risk Classification (Risk Management)
Concept: Simulates the principle of Logistic Regression and Decision Boundaries in risk modeling.

Interaction: Users input hypothetical Annual Income and Debt-to-Income (DTI) Ratio for a loan applicant.

Key Lesson: The model instantly classifies the applicant as Approved or Denied, showing how weighted features contribute to a risk score that crosses a defined decision threshold.

Module 3: Algorithmic Trading Signals (Time Series Strategy)
Concept: Illustrates the iterative nature of Time Series Analysis and Algorithmic Policy Generation.

Interaction: Clicking "Run 10 Steps" advances a simulated stock price chart and prompts a trading "Agent" to generate an instantaneous Buy (▲) or Sell (▼) signal based on simple momentum.

Key Lesson: Highlights that algorithmic trading decisions are based on the latest market context and predefined rules (policies), promoting an understanding of backtesting and sequential decision-making.
